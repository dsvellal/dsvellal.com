What it is

The problem

Release and submission readiness is slowed by fragmented DHF execution. Requirements, risks, tests and design evidence are disconnected, so traceability reconstruction, impact assessment and 510(k) submission evidence stay manual and prone to gaps.

The approach

Ingest and normalize DHF artifacts (requirements from ALMs, test cases and results, release documents), model the relationships in a graph database aligned to the V-model, visualize traceability, impact and requirements-to-test gaps, add AI for gap remediation and natural-language query, with human approval preserved.

Why it matters

AI traceability platform is an AI-powered V&V compliance platform that links design-history evidence in a graph database to give traceability, change-impact analysis and test-gap detection for medical device software.

What happened

Golden Thread Traceability (the traceability tool)

Ingests release documents from the businesses and shows end-to-end links (need, requirement, design, risk, test, result) as a graph, upstream and downstream.

Impact Assessment (impact analysis)

Shows which requirements, tests and other artifacts are affected when a requirement changes, with severity and a reason why each node appears.

Test scenario gap detection and generation

Finds requirements without test coverage and uses generative AI to propose test scenarios. First iteration only; live for a business unit first, SRC and a business unit planned after data validation.

2D/3D graph exploration, search, orphan-node view and export

Interactive 2D and 3D graph with node-type filtering, property search, orphaned-node detection and CSV/JSON export of traceability.

Gremlin query support and Graph Builder

Advanced users can run Gremlin graph queries; the Graph Builder auto-constructs Gremlin queries.

Semantic-search chatbot (natural-language query)

Users ask questions in natural language and get answers based on their ingested data. Described as the final feature planned under the AI compliance platform project; accuracy still being refined.

Automated ingestion pipeline

Automated project creation and infrastructure provisioning plus ingestion and gap identification from business documents; completed for SRC, a business unit and a business unit.

Self-hosted inner-source platform on AWS (Neptune graph)

Runs in business-managed AWS accounts on a Neptune graph database; inner sourced so any team can extend it.

Developer Portal access (no GitHub credentials)

Live the traceability tool data on the internal developer portal so anyone in the organization can open it without GitHub credentials. Staging first; production migration still a next step in Wk 9.

Windchill MCP access

Agent-oriented access to Windchill through MCP is the preferred long-term interface; read-only API is the nearer path and write use cases are not defined.
