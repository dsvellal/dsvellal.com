Code Live technical-challenge clinics (Jul and Sep 2019) and the mutation testing session with RadOnc (Oct 2019)

Jul 2019 to Oct 2019

Code Live is a SWCoE format where a team brings a technical challenge from its own code and experts work on it with them. The July folder holds the challenge submission template; the September folder holds feedback from a session. The October folder holds a survey from a mutation testing exercise with a RadOnc Python team, where Datta and a colleague mentored.

Facts from the documents

  • The Code Live template asks for the challenge description, category, pain points, how they are measured, expected outcome, business value, solutions tried and a suggested expert.
  • The template's worked example is a monolith file with crucial business logic that is prone to bugs, with measures such as line count, coverage, regression time and compiler warnings.
  • A Do's and Don'ts sheet says tool development, library development, third-party tool problems and regular programme backlog are outside the Code Live scope.
  • The Sept Code Live feedback came from participants in HSDP, PSI2M, ICAP and PM business units using C#, Java and others.
  • Participants named takeaways such as a strategy for unit testing static methods and increasing unit test coverage of legacy code.
  • Improvement requests for Code Live: make it more organised and interactive, and give better information on each workshop so people can choose.
  • The mutation testing survey recorded a Python library run with Mutmut: install under 2 minutes, run about 20 minutes, 90 test cases, 955 mutants of which 824 were killed and 131 escaped.
  • After a commit the participant killed 2 more mutants, leaving 129, and said the tool added effectiveness to the unit tests.
  • The participant answered Yes to using mutation testing again and rated the mentoring 10 out of 10 on recommending it.
