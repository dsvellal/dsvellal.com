Led the first CI/CD milestone: automated end-to-end tests

I led the first milestone of the CI/CD drive I had set for identity management in 2019: the team's end-to-end test automation running through Jenkins.

  • Delivery
  • Quality
  • Reliability
Without it
End-to-end tests ran by hand, so every release waited on manual checks.
The call
Automate the slowest check first, then build the pipeline around it.
What I did
Set the milestone and led the contributors who got the end-to-end scripts running through Jenkins.
What changed
The director thanked all the contributors and named it the first step of the CI/CD pipeline drive.
