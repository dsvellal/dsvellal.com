15 May 2023Philips North AmericaTalk

Designed and ran a hands-on code quality workshop for about 50 engineers

I designed and ran a two-hour workshop on design, code, test and review patterns, where engineers reviewed real open-source and shared code knowing they would co-own any bug they approved.

Without it
Engineers would keep reviewing code without shared techniques for spotting problems.
The call
Teach by having engineers review real code together and own what they approve.
What I did
Built the review exercises and anti-pattern examples, and led the session in the room and online.
What changed
About 50 engineers took part, 12 in the room and 38 online. The announcement was seen by 1,103 people, and a leader asked to run these sessions more often.
