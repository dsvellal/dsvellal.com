Led a proof of concept to run ultrasound tests on virtual machines

I led a phase 1 proof of concept in which Software Excellence and the Ultrasound team moved a simulator test suite from physical hardware to virtual machines.

test run on a virtual machine

phase 1 proof of concept

Without it
Tests would stay tied to scarce physical machines, with little room for automation or parallel runs.
The call
Prove virtualization with a narrow first phase before asking the business for more.
What I did
Coordinated the people who produced the OS image, the virtual machine setup and the test run, then shared the result with Ultrasound R&D and credited everyone involved.
What changed
Both sanity suites passed on a virtual machine in about 3 minutes; an engineering leader called the work the 'art of possibility'.
